# PC-ALM 재현 및 MaleCNS 실제 학습 검증

**실행 완료:** 공식 Fashion-MNIST 기준 셀 3회 학습 + MaleCNS 개발30회/평가25회 학습 + 개발 체크포인트3회 재현 및36개 추론 예산 진단. 추가 실행 점검1회는 별도 기록. 신규 알고리즘의 우위나 논문 신규성을 확정한 실험은 아니다.

## 연구주제와 주요 질문
**실제 MaleCNS 연결 제약에서 PC-ALM이 정확하고 유용한 학습을 수행하는 조건.**
1. 공식 구현의 성능이 재현되는가?
2. 실제 부분 회로에서 PC-ALM으로 정답 라벨을 학습할 수 있는가?
3. 오류 신호의 전달 방향을 제한하면 실제 학습에 어떤 차이가 생기는가?
4. 내부 회로 학습이 출력층만 학습하는 것보다 유용한가?
5. 향후 보정법이 동일한 통신 비용으로 학습 신호와 과제 성능을 함께 개선할 수 있는가?

[사전에 고정한 계획](PROTOCOL.md)은 수식·데이터 분할·가설·실패 조건·참고문헌을 포함한다. [추가 예산 진단 계획](BUDGET_AUDIT_PROTOCOL.md)은 초기 학습 결과를 본 뒤 작성한 개발 단계 진단이며 사후 계획임을 명시했다. 최초 프로토콜은 소급 수정하지 않았다. 로컬 해시 고정은 공개 외부 사전등록과 다르다.

## 1. 공식 PC-ALM 재현: 통과
공식 커밋 `660747f61a8a7e547c0ecd2c48c8883380a7d1f6`의 코드를 수정하지 않았다. 잠금 파일로 환경을 설치했고 테스트15개를 통과했다. Fashion-MNIST 전체 학습60000/시험10000, 폭32/깊이32/ReLU/seed0/1epoch/T64로 실행했다.

| 방법 | 공식 README 정확도 | 이번 재현 정확도 |
|---|---:|---:|
| BP | 78.66% | 78.65% |
| PC | 68.13% | 68.17% |
| PC-ALM | 77.75% | 77.73% |

사전 기준인 각 정확도 차이2%p 이내, PC-ALM>PC를 모두 통과했다. **공식 결과의 단일 셀 재현이며 논문 전체/1000층 재현은 아니다.** [원시 결과](upstream_results/cells.csv), [환경·데이터 해시·테스트 기록](upstream_provenance.json), [공식 저장소](https://github.com/SakanaAI/pc-alm).

## 2. MaleCNS 학습 실험: 학습 가능성 확인
공식 원자료와 대조된 132뉴런/2663연결을 사용했다. 실제 손글씨900개로 학습,300개로 학습률 선택,597개로 평가했다. 모든 방법에 동일한 두 학습률과3개 개발 시드를 제공한 뒤, 선택을 고정하고5개 새 시드로 평가했다. 각20epoch. 방법별 최종epoch만 평가했다.

모델은 **선형 순환 회로의 평형 모델**이다. 입력은 모든 뉴런에 고정 무작위 투영하고, 기존24개 하행 뉴런에서 출력한다. 측정된 배선과 실제 손글씨를 사용하지만, 입력 위치·동역학·가중치 크기는 공학적 가정이다. 초파리 시각 기능이나 생물학적 학습을 재현한 것으로 해석하지 않는다.

| 방법 | 평균 시험 정확도 ± 시드 표준편차 | 평균 시험 손실 ↓ |
|---|---:|---:|
| 정확한 암묵미분 기준 | 86.33 ± 1.71% | 0.233639 |
| PC | 87.37 ± 1.85% | 0.230570 |
| PC-ALM | 87.34 ± 1.75% | 0.227765 |
| 피드백 방향 제한 ALM 대체식 | 87.14 ± 1.53% | 0.231468 |
| 회로 고정·출력층만 학습 | 83.52 ± 2.14% | 0.250407 |

손실=.5×샘플별10차원 제곱오차합의 평균. 표준편차는 생물학적 개체 차이가 아닌 초기화·최적화 시드 변화다. 정확한 암묵미분은 평형 모델의 기준이며 BPTT라고 부르지 않는다.

- **작동:** PC-ALM은 단순 우연 수준10%를 넘어서 학습했고 사전 학습 가능성 기준을 통과했다.
- **회로 학습:** 출력층만 학습한 대조군 대비 정확도 약3.82%p 상승, 평균 손실 약9.04% 감소. 출력층만의 효과로 설명되지는 않는다는 초기 근거다.
- **PC 대비:** 평균 손실은 약1.22% 낮지만 정확도는 사실상 같다. paired 손실차(ALM-PC)=-0.002806, 탐색적95% t구간[-0.008620,0.003009]. **PC보다 확실히 좋다는 결론은 불가.**
- **피드백 제약:** 제한 대체식보다 평균 손실은 낮지만 paired 구간이0을 포함한다. 배선 제약이 실제 정확도를 반드시 크게 악화시킨다는 주장은 지지하지 않는다.
- **정확한 미분 대비:** 이번 제한된 설정에서 ALM 평균 손실이 낮지만, 최적화·유한 추론·정규화 효과가 혼재하므로 일반적인 BP 우위 주장 불가.

## 3. 학습된 회로에서 추론 횟수의 영향
선택된 개발ALM 체크포인트3개를 재현했으며 기존 검증 손실과의 차이는1e-12 미만이다. 시험 자료는 진단에 쓰지 않았다. 동일 체크포인트·훈련 샘플에서 학습 방향 오차를 비교했다.

| 추론 횟수 | PC-ALM gradient 상대오차 | 방향 제한 대체식 |
|---|---:|---:|
| 8 | 36.03% | 38.25% |
| 32 | 14.66% | 27.99% |
| 128 | 7.96% | 28.02% |
| 512 | 0.64% | 28.09% |

**정확한 신호 전달을 허용하면 반복 횟수로 줄일 수 있는 오차와, 방향 제약 때문에 반복해도 남는 오차가 구분됐다.** 이는 기존 이론과 일치하는 메커니즘 확인이다. 512회로 재학습했거나 시험 정확도가 좋아졌다는 뜻은 아니다. [전체 진단](budget_audit_results/probes.csv).

## 4. 검증·한계와 다음 실험 계획
유한차분 gradient 검증, PC와 alpha=0 ALM의 일치, 부호/마스크/스펙트럼 제약, 데이터 분리, 원자료 체크섬을 확인했다. [검증 결과](results/verification.json).

모든 방법이 학습률 격자의 상단 .003을 선택했다. 현재 결과를 충분히 튜닝된 알고리즘의 성능 한계로 해석하면 안 된다. 데이터 분할은 고정되어 있고 평가 시드는5개뿐이며, 단일 부분 회로를 사용했다. 시험 결과를 본 뒤 같은 시험 세트로 방법을 반복 선택하면 과적합된다. 향후 확인 연구는 새로운 외부 과제 또는 별도 고정 holdout이 필요하다.

입력 평형 계산·스펙트럼 투영은 전역 연산이다. 국소 학습식이라도 전체 구현이 생물학적으로 국소적이거나 BP보다 효율적이라는 뜻이 아니다. 피드백 대체식은 연결 방향만 제한하며 신경전달물질 부호까지 보장하지 않는다. masked의 장기 gradient 오차가 커도 방향 cosine은 높을 수 있어 과제 차이가 작을 수 있다. readout 행의 gradient 진단은 적용하지 않은 내부 gradient의 참고값이므로 내부 학습을 뜻하지 않는다(W변화0 확인).

다음 단계는 아래 순서로 진행한다. 이번 실행 범위는1–3단계의 개발 검증이며, 나머지는 완료되지 않았다.

| 단계 | 상태 / 진행 조건 |
|---|---|
| 공식 PC-ALM 기준 재현 | 완료, 통과 |
| 실제 배선에서 학습·출력층 대조 | 완료, 통과 |
| 학습된 상태의 추론 예산 진단 | 완료, 이론 예측과 일치 |
| 비선형 flyvis 기준 재현 | 미실행. 먼저 기존 구현의 기능적 기준 확보 |
| 보정법 선정·신규성 대조 | 미완료. feedback alignment/weight transport/PC 선행연구 대비 차별점 필요 |
| 개발 튜닝 확장 | LR 상단 확장, T32/64/128, 동일 튜닝 기회, 별도 개발 데이터에서 결정 |
| 확증 실험 | 위 단계 통과 후 새20시드·독립적으로 선정한3회로·새 평가 과제. 효과크기/정밀도·다중비교 계획 사전 고정 |

현재 적절한 논문 주장은 '측정된 회로에서 PC-ALM의 작동 조건을 검증하고 피드백 제약과 유한 추론의 영향을 분해했다'는 **예비 결과** 수준이다. 새로운 알고리즘의 우위·최초 연구·SCI 게재 가능성을 확정하지 않는다.

## 재현
원자료가 없으면 저장소의 `experiments/credit_rebuild/download.sh`로 받는다. Python 환경을 분리하는 것을 권장한다.

```bash
python -m pip install -r experiments/feedback_learning/requirements.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python experiments/feedback_learning/study.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python experiments/feedback_learning/budget_audit.py
bash experiments/feedback_learning/reproduce_upstream.sh /absolute/new/upstream-checkout
```

`study.py`의 results 및 budget_audit_results가 이미 있으면 중단한다. 재현 시 기존 결과를 보관하고 새 실행 위치를 준비한다. 결과 폴더의 JSON/CSV가 전체 실행의 정본이다. 부가 stdout 로그는 실행 환경의 스트림 저장 제약으로 일부만 남아 있어 완전한 기록으로 사용하지 않는다. 별도 점검의 중복 실행은 추가 시드나 독립 결과로 세지 않는다.
