# MaleCNS에서 PC-ALM의 학습 신호 전달 검증

## 연구주제
**실제 초파리 회로의 연결 제약 아래에서 PC-ALM의 학습 신호 정확도와 성능 개선 조건 규명.**

연구의 목적은 초파리 배선의 우월성을 주장하는 것이 아니라, 해당 배선에서 PC-ALM이 언제 작동하고 무엇을 보정해야 하는지 밝히는 것이다.

- RQ1: 정확한 피드백을 허용하면 실제 부분 회로에서 올바른 학습 방향을 회복하는가?
- RQ2: 피드백도 측정된 방향의 연결만 쓰도록 제한하면, 수렴 이후에도 오차가 남는가?
- RQ3: 같은 통신 예산에서 보정 방법이 학습 방향과 실제 과제 성능을 개선하는가?
- RQ4: 다른 부분 회로와 독립적인 실제 자극에서도 재현되는가?

## 엄밀한 정의와 선행연구 검토
[PROTOCOL.md](PROTOCOL.md)에 수식, 가정, 참고문헌 9건, 사전 예측, 신규성 판단과 본 실험 진입 조건을 기록했다. 프로토콜·실행 코드 해시를 기록하고, 반복 계산 전에 [예측값](results/predictions_before_inference.csv)을 저장했다. 이는 공개 외부 사전등록은 아니다.

PC-ALM의 선형 안정성과 임의 계산 그래프의 예측 코딩은 기존 연구다. 비대칭 피드백/weight transport도 기존 문제다. 새로운 방법의 발명이나 세계 최초를 주장하지 않는다. 후보 기여는 실제 회로의 학습 신호 전달 조건을 정량화하고, 동일 통신 비용의 해결책까지 검증하는 것이다. 그 신규성은 아직 확정되지 않았다.

## 완료한 진단 실험
5개 시드 × 2개 가중치 크기 × 3개 방법 = **30개 추론 궤적**, 각 4096회. 가중치를 학습한 30회 실험이 아니다.

공식 MaleCNS 원자료의 SHA-256을 확인했고, 기존 132뉴런 부분 회로의 2663개 연결과 시냅스 수를 원자료에 다시 대조했다. 연결당 시냅스 5개 이상이라는 기존 선택 기준을 유지했다. 이 임계값 아래 연결과 부분 회로 바깥 경로는 포함하지 않는다.

선형 평형 h=(I-W)^(-1)u에서 정답 gradient를 직접 계산했다. 입력 전류·목표는 합성이며, 가중치 크기·뉴런 동역학도 공학적 가정이다. 표의 g는 ||W||_2이다.

| 방법 | g=0.4 최종 gradient 상대오차 | g=0.8 최종 gradient 상대오차 |
|---|---:|---:|
| 정확한 피드백 PC-ALM | 약 7.1e-16 | 약 7.4e-16 |
| 연결 방향 제한 ALM 대체식 | 6.66% | 13.94% |
| PC, 고정 penalty=1 | 60.90% | 61.62% |

5개 시드 평균, 4096회 추론 후. 위 수치는 정확도/과제 성능 개선율이 아니다. PC의 유한 penalty 편향은 알려진 차이이며, penalty 튜닝을 하지 않은 이 표는 일반적인 PC 성능 순위가 아니다.

정확한 ALM은 32회에서도 평균 상대오차가 1.56% / 1.88%였다. 반면 방향 제한 대체식은 충분히 반복한 후에도 6.66% / 13.94%에 머물렀다. 양쪽 모두 제약 잔차는 약 1e-15까지 줄었다. 즉 **상태가 회로 방정식을 만족한다고 학습 방향까지 정확한 것은 아니다.**

선택한 그래프의 2663개 방향 연결 중 1515개(56.89%)는 같은 선택 그래프 안에 직접 역방향 연결이 없었다. 이는 전체 뇌에서 역방향 통신이 불가능하다는 뜻이 아니다. 다중 경로·세포 내부 계산·보조 뉴런·약한 연결은 별도 고려해야 한다. 정확한 ALM은 추가 오류/dual 통신을 가정한다. 제한 대체식 역시 피드백의 전달물질 부호까지 만족시키는 생물학적 모델은 아니다.

## 검증 결과와 해석 범위
- 30개 조건 모두 실행 전 spectral radius <1: 안정성 예측.
- 독립적인 유한차분으로 참 gradient 확인.
- 반복 계산과 해석적 행렬 점화식 일치(상대오차 <1e-9).
- 정확한 ALM의 최종 gradient 상대오차 <1e-5 기준 통과.
- 원자료 체크섬 및 선택한 연결의 값 대조 통과.
- [수치 검증 기록](results/verification.json), [전체 궤적](results/trajectories.csv), [요약](results/summary.csv), [출처 해시](results/manifest.json).

수학 검증과 첫 작동 검증은 통과했다. **비선형 학습 성능, 실제 영상 일반화, 보정 알고리즘의 이득은 아직 검증하지 않았다.** 이 결과가 이전 움직임 실험 실패의 원인임을 입증한 것도 아니다. 해당 실험은 정확한 전치 연산을 허용한 다른 모델이었다.

## 본 실험 계획과 진행 조건
1. 공식 PC-ALM 및 flyvis 기준 모델을 먼저 재현한다.
2. 피드백 정렬·weight transport·PC 비대칭 피드백 선행연구와 후보 보정법을 수식/코드 수준에서 대조한다. 단순 전치 연결 추가나 기존 정렬 기법 재사용만으로 신규성 주장 금지.
3. 5개 개발 시드에서 비선형 모델이 단순 기준선보다 학습하는지 확인하고, 보정이 같은 통신 비용에서 gradient 오차를 줄이는지 확인한다.
4. 통과하면 20개 새 paired seed, 별도 회로 3개, 동일 튜닝 예산으로 본 실험. 주지표는 미사용 평가 데이터의 과제 손실. 학습 신호 오차·잔차·실패율·시간·메모리·통신량은 부지표.
5. 영화/기록 단위로 먼저 분리한 뒤 crop/window를 생성한다. 렌더링 영상과 실제 촬영/신경기록을 구분한다. 비열등성 한계·효과 크기/정밀도 계획은 개발 결과로 결정하고 본 실험 전에 고정한다.

현재 진행 상태: **진단 완료, 본 실험 보류**. 사용자의 '계획을 검증하고 신규성과 예상 성능의 근거가 갖춰진 후 시작' 조건에 따라 대규모 학습으로 넘어가지 않았다. 다음으로 검증할 후보는 제한된 통신 경로에서의 다중 홉 피드백 또는 보조 경로 학습이며, 현재는 구현/성능을 확보한 새 알고리즘이 아니다.
