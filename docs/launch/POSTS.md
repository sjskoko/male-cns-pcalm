## English: personal developer/research account

Can a network wired from a fruit fly learn with local updates?

I’m sharing MaleCNS × PC-ALM: a research sandbox built around a real connectome-derived feedforward circuit (132 neurons, 1,001 connections).

The result is mixed: PC-ALM learns, but did not outperform standard predictive coding in our tested settings. Better initial gradient alignment did not translate into better final error.

The repository includes 760 training fits, paired controls, source checksums, and a CPU notebook that runs a small live example. Synthetic targets; not a whole-brain simulation. Development and implementation were AI-assisted.

Try it: https://github.com/sjskoko/male-cns-pcalm
Notebook: https://colab.research.google.com/github/sjskoko/male-cns-pcalm/blob/main/examples/quickstart.ipynb

Independent reproductions and critiques of the finite-inference-budget comparison are welcome.

## Korean: personal developer/research account

초파리 뇌의 실제 배선을 가져와 AI를 학습시키면 어떨까요?

MaleCNS 연결 지도에서 뉴런 132개와 연결 1,001개를 추린 뒤, 국소 학습 방식인 PC와 PC-ALM을 비교한 연구용 코드를 공개했습니다.

결과는 기대와 달랐습니다. PC-ALM은 학습했지만, 이번 조건에서 일반 PC보다 성능이 좋아지지는 않았습니다. 초기 기울기 방향이 역전파에 더 가까워져도 최종 오차가 낮아지는 것은 아니었습니다.

760회 학습 기록과 대조 실험을 공개했고, GPU 없이 직접 작은 학습을 실행하는 노트북도 추가했습니다. 전체 뇌 시뮬레이션은 아니며 정답 데이터는 합성 과제입니다. 개발과 구현에는 AI의 도움을 받았습니다.
